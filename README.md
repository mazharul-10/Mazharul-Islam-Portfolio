# Md. Mazharul Islam — Portfolio

This project was separated from the original self-contained HTML file.

## Project structure

- `index.html` — portfolio page
- `css/style.css` — original embedded styles
- `js/script.js` — original JavaScript and portfolio content
- `assets/` — extracted WebP images

## Run locally in VS Code

1. Extract this folder.
2. Open the `Mazharul_Islam_Portfolio` folder in VS Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Publish with GitHub Pages

1. Create a new GitHub repository (for example, `my-portfolio`).
2. Upload/push all files and folders in this project; keep the folder structure unchanged.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The public URL will appear in the Pages section.

## Notes

- The original design, text, and JavaScript behavior have been retained while separating CSS, JS, and embedded image assets.
- Google Fonts are loaded from Google Fonts, so an internet connection is needed for those fonts. System fallback fonts remain available.
- Review contact details and public profile links before publishing.
